# Changelog

## v0.3.0 — 2026-11-04
CodeRabbit-style automation, rebuilt to stay free: no AI in the verdict, no API keys, no server.

- **PDF input**: `coi-lint extract`, and `check` / `renewals` / `report` accept PDFs. Reads fillable form fields (pypdf), then the text layer (pdfplumber), then OCR for scans (Tesseract, optional), using a YAML **field map** (`--fieldmap`). Unreadable fields fail as **COI009**; OCR'd certificates warn as **COI010** (verify the values). Size and page limits on input.
- **Fix suggestions** on every failing/warning finding (text, JSON `fix` field, and "Requested:" lines in letters). **`coi-lint explain <rule>`** explains any rule, including pack rules.
- **Waivers** (`--waivers waivers.yaml`): turn a known exception into "waived" with a reason, approver and required expiry date; expired waivers are flagged. `coi-lint waivers` shows which rules get waived most.
- **Rule packs** (YAML, declarative, can't run code) and **`extends:`** config inheritance with `insured_overrides`. Example: `packs/strict-gc-example.yaml`, `examples/requirements-strict.yaml`.
- **`coi-lint report`**: project summary as Markdown, a self-contained HTML dashboard (Design.md colours, light/dark), a CSV register, or JSON.
- **`coi-lint watch-inbox`**: IMAP watcher that checks certificate attachments as they arrive and saves a reply to Drafts. Never sends, deletes or marks emails as read; password from an env var.
- **Slack** headline via your own incoming webhook (`--slack-env`).
- **JSON Schemas** (`schemas/`) + VS Code settings for autocomplete; **CI** workflow; reusable **GitHub Action** (`action.yml`) with a Pages example; **pre-commit** hook.
- Sample certificate as fillable, flat and scanned PDFs (`examples/pdfs/`, regenerated by `scripts/make_sample_pdfs.py`). 39 tests.

## v0.2.0 — 2026-10-30
Renewal tracking, based on feedback from someone working in compliance: the chasing starts all over again every renewal cycle.

- New `coi-lint renewals <files/dirs>` command: every policy across many certificates, soonest expiry first, grouped into expired / 30 / 60 / 90-day windows. `--within`, `--rules` (only required coverages), `--format text|json|letter`. Exit code `1` if anything shown has expired.
- `--ics renewals.ics`: calendar file with one all-day event per upcoming expiry and reminders 90, 60 and 30 days before. Stable UIDs, so re-importing updates events instead of duplicating them.
- `--format letter`: one renewal-request draft per broker, listing all their clients' policies due. Drafts only, never sent.
- Two more fictional example certificates in `examples/certs/`; 7 new tests (11 total).
- SKILL.md teaches agents the renewals workflow.
